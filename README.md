# 🌐 Buddy Script Frontend

Frontend application for **Buddy Script** – a modern social media platform where users can share posts, react, comment, and interact in real-time.

---

## 📌 Project Overview

Buddy Script Frontend is built using **Next.js (App Router)** and provides a fast, responsive, and user-friendly interface for users to interact with the platform.

---

## ⚙️ Features

- 🔐 Authentication (Login / Registration)
- 🏠 User Feed (All Posts)
- 👤 User Profile & My Posts
- 📝 Create / Update / Delete Posts
- 🔒 Privacy Control (Public / Private)
- ❤️ Like / Dislike System
- 💬 Comments & Replies
- 📸 Image Upload Support
- ⚡ Dynamic Rendering (SSR + CSR)
- 🎨 Responsive UI with Tailwind CSS

---

---

## 🛠️ Tech Stack

- Next.js 16 (App Router)
- React.js
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth (Frontend Integration)
